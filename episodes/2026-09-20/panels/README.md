# 031화 〈압력 이동〉 패널 자산 명세

현재 상태: 원고·최종 대사·아트 지시 완료, 이미지 미제작. 이 폴더에는 이 README만 둔다. 이미지 생성·유료 API·퍼블리셔 실행·커밋·배포는 이번 작업 범위에 없다.

추후 제작 시 세로 1024×1536 PNG 12장을 아래 경로에 둔다. 파일 경로는 [metadata.json](../metadata.json)의 `panels[].file`과 일치해야 한다. 기존 이미지를 대신 복사하거나 빈 이미지로 채우지 않는다. WebP를 선택한다면 해당 metadata 경로도 함께 일치시켜야 한다.

| 패널 | 예정 파일 | 장면 |
| --- | --- | --- |
| 01 | `01.png` | 서랍을 닫기 전에 |
| 02 | `02.png` | 남은 두 서명 |
| 03 | `03.png` | 도시락을 든 아이 |
| 04 | `04.png` | 받는 사람 |
| 05 | `05.png` | 점심은 식기 전에 |
| 06 | `06.png` | 갈아 끼운 종이 |
| 07 | `07.png` | 하나부터 네 장 |
| 08 | `08.png` | 두 번의 새벽 |
| 09 | `09.png` | 새 종이에도 |
| 10 | `10.png` | 먼저 알려 줄 것 |
| 11 | `11.png` | 아직 쓰지 않은 것 |
| 12 | `12.png` | 이름보다 먼저 |

[SCENARIO.md](../SCENARIO.md)의 대사가 최종본이며 metadata에 같은 순서로 수록되어 있다. [ART_PROMPTS.md](../ART_PROMPTS.md)의 패널별 구도·빛·팔레트·연속성·금지 요소를 따른다. 한국어 alt 12개는 metadata에 있다.

검수 핵심: 첫 패널은 030화의 열린 서랍을 그대로 잇는다. 022화 낱장에는 서명 둘만 남고 붉은 선이 없다. 병원의 교체 명찰 네 장과 재출력 한 장, 미사용 99번은 구별한다. 마지막 명찰은 가려진 이름이 아니라 처음부터 빈 이름 칸이다. 99는 양식 번호이지 아기 수가 아니다. 서리의 왼쪽 어깨와 태오의 두 손바닥 부상, 실의 무색 구간, 마리 머리 위 선을 유지한다.
