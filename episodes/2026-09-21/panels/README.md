# 032화 〈아흔아홉 이름〉 패널 자산 명세

현재 상태: 원고·최종 대사·아트 지시 완료, 이미지 미제작. 이 폴더에는 README만 둔다. 아래는 추후 제작 경로이며 빈 이미지나 기존 회차 이미지로 대신 채우지 않는다.

세로 1024×1536 PNG 12장. 경로는 [metadata.json](../metadata.json)의 `panels[].file`과 동일하다.

[SCENARIO.md](../SCENARIO.md)의 대사·내레이션은 최종본이며 metadata와 순서·문구가 같다. [ART_PROMPTS.md](../ART_PROMPTS.md)는 각 장면의 구도·빛·팔레트·연속성·금지 요소와 한국어 alt를 제공한다.

검수 핵심: 첫 컷은 031화 마지막 명찰 부감을 잇는다. 미사용 99장과 교정한 네 장, 재출력 사본 한 장은 별개다. 네 교정의 값은 7+9=16획이며 선은 04:12까지 남는다. 99번에는 이름·정자·교정 실을 넣지 않고 마지막에 뒷면 압흔 네 곳만 드러낸다. 서리의 어깨, 태오의 손바닥, 마리 머리 위 선, 실의 무색 구간을 유지한다.

이번 작업에서는 이미지 생성·API 호출·퍼블리셔 실행·커밋·배포를 하지 않는다.
