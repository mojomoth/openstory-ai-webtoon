각 파일은 독립된 세로 1024×1536 PNG로 지정한다. 한 이미지를 여러 패널 경로에 재사용하거나 합본으로 대체하지 않는다. 경로 기준은 이 회차 디렉터리이며, 실제 저장 위치는 이 README와 같은 폴더의 `01.png`부터 `11.png`까지다.

[시나리오](../SCENARIO.md), [아트 프롬프트](../ART_PROMPTS.md), [메타데이터](../metadata.json)의 번호·경로·한국어 alt·대사를 맞췄다. 대사는 이미지에 직접 넣지 않고 메타데이터의 배열 순서대로 별도 오버레이·접근성 대본에서 사용한다.

직전 033화 마지막 이미지 파일은 이 작업 사본에 없다. 첫 패널은 직전 SCENARIO·ART_PROMPTS의 수첩·제안서·오른손 부감 지시를 따른다. 마지막은 수첩 왼쪽, 축소 사본 오른쪽, 마리 손 오른쪽 모서리, 서리 오른손 아래쪽, 은모 빈손 위쪽 배치를 다음 회차에 넘긴다.

향후 이미지 작업 시 각 패널의 개별 구도·빛·금지 요소와 기존 기억 손실·부상을 유지해야 한다. 이미지 생성·게시·배포·커밋은 이번 작업에 포함하지 않았다. API 키·유료 API·Claude를 사용하지 않았다.
