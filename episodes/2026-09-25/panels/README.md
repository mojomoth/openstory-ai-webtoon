각 경로는 에피소드 폴더 기준이며 이 디렉터리에서는 `01.png`부터 `10.png`까지다. 향후 별도 요청으로 제작할 경우 각각 독립된 세로 1024×1536 래스터 패널을 사용한다. WebP로 바꿀 때는 해당 회차의 메타데이터·대본·아트 지시·이 표의 확장자를 함께 맞춘다.

01은 035화 마지막 부감의 종이와 손 배치를 이어받는다. 10은 삼광 출입문 안쪽, 마리가 판지에 시험쇄를 받치고 서리가 오른손으로 가방을 드는 구도다. 찢긴 가장자리·먹 취소선·하단 서명은 전 컷에서 보존한다. 부상·기억 손실·마리의 기존 선은 아트 지시를 따른다.

모든 패널에는 metadata의 한국어 alt와 비어 있지 않은 dialogue 배열이 있다. 04의 첫 문장은 내레이션이다. 인물별 발화자는 SCENARIO에 명시했다. 말풍선·내레이션·이름은 이미지 안에 직접 그리지 않고 별도 오버레이와 접근성 대본으로 전달한다.

이번 작업에서는 이미지 생성·API 호출·키 사용·유료 API·Claude 호출·게시·배포·커밋을 실행하지 않는다. 사용자 요청에 따라 퍼블리셔도 실행하지 않는다. 이미지 존재 검사와 실제 렌더링 검수는 자산 제작 전이므로 미완료이며, 현재 파일을 게시 가능한 이미지 완성본으로 취급하지 않는다.
